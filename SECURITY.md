# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues, discussions, or pull requests.

If GitHub offers private vulnerability reporting for this repository, open the **Security** tab and select **Report a vulnerability** to start a private security advisory. Include the affected version or commit, impact, and steps to reproduce when possible. You may also include a suggested mitigation. The maintainers will coordinate any fix and disclosure through the advisory.

If private vulnerability reporting is unavailable, contact the repository owner privately through GitHub before sharing any details publicly.

## Scope

This policy covers the TWX Analyzer v2 source code and its maintained build and deployment configuration. Please report suspected vulnerabilities in those components, including dependency vulnerabilities that can affect this project.

The application is designed for a closed, trusted intranet and does not provide general user authentication. A deployment that exposes it beyond that environment is not a supported security boundary; see the deployment and security guidance in the project documentation.
