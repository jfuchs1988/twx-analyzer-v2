# 12 — Glossary

| Term | Meaning |
| --- | --- |
| BAW | IBM Business Automation Workflow |
| BPM | Business Process Management; here, primarily the BAW Operations API/import |
| TWX | Export/archive file for a Process Designer project or toolkit |
| Snapshot | Imported TWX state with metadata, objects, and analysis results |
| Toolkit | Reusable BAW package that can be included by applications or other toolkits |
| Finding | A quality-rule hit associated with an object or source location |
| Quality gate | Evaluation of findings against configurable thresholds |
| Ingest | Upload/import, parsing, persistence, and analysis of an export |
| ADR | Architecture Decision Record; a documented architecture decision |
| CSRF token | Token returned by the BAW Operations login flow and required for API requests |
